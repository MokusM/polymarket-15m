# Індикатори для SOL/BTC 5m Arb — Повний гайд

## 1. EMA (Exponential Moving Average) — Напрямок тренду

**Що це:** Середня ціна за N останніх свічок, але новіші свічки мають більшу вагу.

**Налаштування:** EMA 9 (жовта) + EMA 21 (синя)

**Як читати:**
- EMA9 ВИЩЕ EMA21 → **BULL** (ціна росте)
- EMA9 НИЖЧЕ EMA21 → **BEAR** (ціна падає)
- EMA9 ПЕРЕТИНАЄ EMA21 знизу вгору → **зміна тренду на бичий**
- EMA9 ПЕРЕТИНАЄ EMA21 зверху вниз → **зміна тренду на ведмежий**

**Для арб:**
- EMA9 ≈ EMA21 (жовта і синя поруч) → ринок невизначений → хороший момент для арб
- EMA9 далеко від EMA21 → сильний тренд → одна сторона вже дорога, арб ризикований

**Для Polymarket:**
- BULL → UP дорожчає, DOWN дешевшає
- BEAR → DOWN дорожчає, UP дешевшає
- Перетин EMA → можливий розворот на Polymarket, протилежна сторона може подешевшати


---

## 2. VWAP (Volume Weighted Average Price) — Справедлива ціна

**Що це:** Середня ціна за день, зважена по об'єму. Показує "справедливу" ціну — де більше всього торгували.

**Як читати:**
- Ціна ВИЩЕ VWAP → покупці сильніші, SOL "дорога" відносно середнього
- Ціна НИЖЧЕ VWAP → продавці сильніші, SOL "дешева"
- Ціна БІЛЯ VWAP (vs VWAP = 0%) → баланс, ринок не визначився

**Для арб:**
- vs VWAP близько до 0% → **найкращий момент** для арб (50/50 на Polymarket)
- vs VWAP > 0.1% → UP сильніший, може бути пізно для арб
- vs VWAP < -0.1% → DOWN сильніший

**Чому важливий:** VWAP як магніт — ціна часто повертається до нього. Якщо SOL відійшла далеко від VWAP → можливий повернення → розворот на Polymarket.


---

## 3. Bollinger Bands (BB) — Волатильність

**Що це:** Канал навколо середньої ціни. Ширина каналу = наскільки волатильний ринок.

**Налаштування:** SMA 20, 2 стандартних відхилення

**Як читати:**
- **Вузькі BB (BB Width < 0.15%)** → ринок спокійний, ціна стоїть → FLAT → найкращий для арб
- **Широкі BB** → висока волатильність, ринок рухається сильно
- Ціна торкнулась **верхньої** BB → можливий відкат вниз
- Ціна торкнулась **нижньої** BB → можливий bounce вгору

**BB Width в таблиці:**
- < 0.15% (зелений) → низька волатильність → ARB зона
- 0.15-0.30% → нормальна
- > 0.30% → висока, обережно

**Для арб:** Вузькі BB = ціна "стиснута", рухається мало. На Polymarket обидві сторони ~50/50. Після стиснення часто йде різкий рух — заходиш в арб під час стиснення, ловиш рух для hedge.


---

## 4. RSI (Relative Strength Index) — Перекупленість/Перепроданість

**Що це:** Показує наскільки швидко і сильно ціна рухалась. Шкала 0-100.

**Як читати:**
- **RSI > 70** → перекупленість (overbought) → SOL росла занадто швидко → можливий відкат
- **RSI < 30** → перепроданість (oversold) → SOL падала занадто швидко → можливий bounce
- **RSI 40-60** → нейтрально → ринок збалансований

**Для арб:**
- RSI 40-60 → **ідеально**, ринок не визначився → обидві сторони ~50/50 на Polymarket
- RSI > 70 → DOWN дешевий (SOL перегріта, UP дорогий) → якщо хочеш directional, купуй DOWN
- RSI < 30 → UP дешевий (SOL перепродана, DOWN дорогий) → купуй UP

**Важливо:** RSI > 70 НЕ означає що ціна обов'язково впаде. Це сигнал що рух був сильним і МОЖЕ бути відкат. На 1m таймфреймі RSI швидко змінюється.


---

## 5. Volume (Об'єм) — Сила руху

**Що це:** Скільки SOL торгувалось за свічку. Показує "впевненість" ринку в русі.

**Vol в таблиці:** Поточний об'єм / середній за 20 свічок

**Як читати:**
- **Vol > 1.5x** (жовтий) → об'єм вище нормального → **сильний рух**, ціна визначається
- **Vol < 0.5x** (сірий) → тихо, мало торгівлі → ціна може стояти на місці
- **Vol = 1.0x** → нормально

**Для арб:**
- Низький об'єм + flat ціна → **ідеально для арб** (ніхто не рухає ціну, 50/50)
- Високий об'єм → ринок визначається, одна сторона скоро буде дорогою
- Volume spike + рух ціни → НЕ входити в арб (ринок вже вирішив)

**Жовті свічки** на графіку = volume spike. Якщо бачиш жовту свічку з великим тілом → сильний рух, чекай.


---

## 6. MACD (Moving Average Convergence Divergence) — Momentum

**Що це:** Різниця між швидкою і повільною EMA. Показує силу і напрямок momentum.

**Як читати:**
- **MACD BULL** → momentum вгору, ціна росте
- **MACD BEAR** → momentum вниз, ціна падає
- **MACD cross** (лейбл "VOL!" якщо з volume spike) → зміна momentum → можливий розворот

**Для арб:**
- MACD BULL + EMA BULL → сильний тренд вгору → DOWN дешевий, UP дорогий
- MACD BEAR + EMA BEAR → сильний тренд вниз → UP дешевий, DOWN дорогий
- MACD близько до 0 → немає momentum → **хороший для арб**

**MACD cross + Volume spike = "VOL!" лейбл** → це найсильніший сигнал що ціна зараз сильно рухнеться. Для арбу це означає: якщо ти вже в позиції → opposite side скоро різко впаде → можливість для hedge.


---

## 7. ATR% (Average True Range) — Волатильність в %

**Що це:** Середній діапазон свічки за останні 14 свічок в процентах від ціни.

**Як читати:**
- **ATR% < 0.05%** → SOL майже не рухається → ідеально для арб (flat start)
- **ATR% 0.05-0.15%** → нормальна волатильність
- **ATR% > 0.15%** (жовтий) → висока волатильність → обережно, може різко рухнутись

**Для арб:** Низький ATR = ціна стабільна = обидві сторони ~50/50 на Polymarket. Високий ATR = ціна стрибає = ризик що одна сторона швидко подорожчає.


---

## 8. Mom 5b (Momentum за 5 свічок) — Поточний імпульс

**Що це:** Зміна ціни за останні 5 хвилинних свічок в %.

**Як читати:**
- **Mom > +0.05%** (зелений) → ціна росте → UP дорожчає на Polymarket
- **Mom < -0.05%** (червоний) → ціна падає → DOWN дорожчає
- **Mom ≈ 0%** (білий) → ціна стоїть → 50/50

**Для арб:** Mom ≈ 0% = найкращий момент. Немає чіткого напрямку.


---

## 9. 5m Range — Рух від старту 5-хвилинного вікна

**Що це:** Максимальний діапазон ціни від початку поточного 5-хвилинного вікна Polymarket.

**Як читати:**
- **< 0.03%** (зелений) → FLAT START → ціна майже не рухнулась від старту → **найкращий арб!**
- **0.03-0.10%** → нормальний рух
- **> 0.10%** (червоний) → сильний рух → ринок вже визначився

**Для арб:** Це найважливіший показник! Flat start = Polymarket 50/50 = обидві сторони дешеві.


---

## 10. Bar# — Хвилина від старту 5m вікна

**Що це:** Скільки хвилин пройшло від початку 5-хвилинного вікна Polymarket.

- Bar 0-1 → початок, ще можна входити
- Bar 2-3 → середина, дивись на ціну
- Bar 4+ → кінець, пізно входити


---

## Комбінації для прийняття рішень

### НАЙКРАЩИЙ сетап для арб:
```
✅ 5m Range < 0.03% (flat start)
✅ RSI 40-60
✅ vs VWAP ≈ 0%
✅ Vol < 1.0x (тихо)
✅ Bar# = 1 (початок вікна)
→ Setup = "FLAT START!" або "ARB OK"
→ /arb одразу!
```

### ХОРОШИЙ сетап:
```
✅ RSI 40-60
✅ EMA9 ≈ EMA21 (жовта і синя поруч)
✅ BB Width < 0.15%
→ Setup = "ARB OK"
→ /arb, але обережніше
```

### DIRECTIONAL (не арб, але можна ставити):
```
RSI > 70 + EMA BULL + Vol > 1.5x
→ SOL перегріта → DOWN cheap на Polymarket
→ Купуй DOWN якщо чекаєш відкат

RSI < 30 + EMA BEAR + Vol > 1.5x
→ SOL перепродана → UP cheap на Polymarket
→ Купуй UP якщо чекаєш bounce
```

### НЕ ВХОДИТИ:
```
❌ 5m Range > 0.10% (ринок визначився)
❌ Vol > 2.0x (занадто активно)
❌ Bar# > 3 (пізно)
❌ RSI > 80 або < 20 (екстремальний рух)
```
